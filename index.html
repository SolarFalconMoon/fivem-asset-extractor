FiveM Dumper · Windows Tool

Dump every FiveM server asset straight to disk

FiveM Asset Extractor is a Windows dumper for FiveM servers. It pulls resources, streamed YTD/YDR models, ymap and meta files and RPFs out of a running server, decrypts the client cache, and resolves asset hashes back to readable names — all in one pass.

Capabilities

Everything a FiveM dumper needs

Built for server owners, modders and researchers who need the actual asset files — not screenshots of them.

📦

Server resource extraction

Walks every resource on the target server and copies Lua scripts, manifests, configs and client files to a clean folder tree on disk.

🚗

Streamed YTD / YDR models

Captures streamed vehicle, ped and prop models — textures inside YTD archives and YDR drawables — with their original file names intact.

🗺️

ymap & meta files

Extracts ymap, ytyp, ybn and every accompanying meta file so custom MLOs and map edits can be reloaded or inspected offline.

🗄️

RPF archive dumping

Unpacks server-side RPF archives, preserving directory structure and exporting embedded assets alongside the rest of the dump.

🔓

Cache decrypt

Decrypts the FiveM client cache so downloaded assets become readable files instead of encrypted blobs, ready for tooling.

🔎

Hash-to-name lookup

Resolves raw asset hashes back to human-readable names using a local dictionary, so you know exactly what you extracted.
